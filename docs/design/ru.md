# Технический дизайн

Анализ в FtaQl выполняет общее ядро на Rust. Через нативный CLI и обёртку для Node.js оно анализирует проекты, а через WASM — отдельные исходные файлы в браузере.

Компоненты распределены по трём каталогам:

- `crates/ftaql` — движок анализа, модель данных JSON, нативный CLI и запись в SQLite;
- `packages/ftaql` — обёртка для Node.js, которая запускает нативный бинарник;
- `crates/ftaql-wasm` — API для анализа одного файла в браузере.

## Анализ проекта

При запуске CLI анализ проходит следующие этапы:

1. Чтение `ftaql.json` и определение конфигурации.
2. Обход файлов через `ignore`.
3. Разбор исходного кода через SWC.
4. Разрешение импортов с учётом `tsconfig.json` и `jsconfig.json`.
5. Анализ связей между файлами и циклов зависимостей.
6. Расчёт метрик и оценок файлов.
7. Сохранение результатов запуска в SQLite.

## Граница между анализом проекта и файла

Анализ проекта доступен через Rust API, нативный CLI и обёртку для Node.js. Он использует файловую систему, чтобы найти исходники и построить граф зависимостей.

WASM получает один исходный файл строкой и не обращается к файловой системе. Поэтому он вычисляет метрики этого файла, но не строит межфайловый граф и не ищет циклы зависимостей.
